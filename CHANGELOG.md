# Changelog

## 1.0.0

- Types for ug-core 1.0.0, generated from its source: every public namespace, enum, hook and event, with server and client forms as overloads.
- The library is added to `Lua.workspace.library` and turned off in workspaces that contain ug-core's source.
- Snippets for callbacks, net events, hooks, events, schemas, Guard, the logger and the manifest.
